## 竞速模式

| 关卡 | 时间 | 每处住宅送达目标 | 住宅数 | 道路预算 |
|---|---|---|---|---|
| 入门 | 60秒 | 5人 | 2 | 28 |
| 晚高峰 | 90秒 | 20人 | 3 | 38 |
| 三轮换线 | 3轮×40秒 | 每轮28人 | 5 | 34 |

前两关每处住宅分别达标即可过关。最终关每轮独立考核，40/80秒检查本轮目标，失败立即结算；通过后站点颜色按橙→蓝→紫→橙轮换，进度归零，在途乘客返回住宅队列，需要重新布线。站点角上的小圆点预告下轮颜色。第三轮全部达标即通关。

积压8人持续10/7/5秒也会失败。最终关暂停遮住地图且不可修路、撤销；免费重试。换轮清空撤销历史，避免恢复上轮已失效的规划。本机榜按同一关卡比较，通关优先、通关者用时越短越好，最终关失败先比到达轮次，再比送达人数。旧最终关成绩保留存储但不参与新版排名，已解锁关卡保留。

自动模拟验证三关均有解。最终关固定开局路网不能通关；每次换轮拆路后留5秒再重建的参考方案可以通关，延迟8秒失败。这是程序模拟，不等于真人难度或5%通关率，后者需要真实玩家样本。

## 操作

拖动连接住宅与同色方形站点，车辆自动寻路和送达。横竖画路，擦路回收道路，右键也可擦路；撤销最近一次操作。前两关暂停时可以规划道路，最终关不允许。只有一座可移动的桥，先擦旧桥才能换位置。

今日同题按北京时间日期固定地图，可重复挑战。切后台或打开弹窗会冻结游戏时间；刷新丢失当前对局，结算成绩和关卡解锁保存在本机浏览器。

## 模拟广告

积压失败后可观看5秒假广告救场一次，仅限闯关模式，最终成绩标记辅助且不进入正式记录列表。结算可看5秒假广告领取额外装饰券。提前关闭不发奖励，播放完需点击领取。没有外部广告请求或付费。

装饰券目前仅为演示积分，未开放兑换。排行榜是本机记录，不是好友/全国排行榜。分享会复制每日同题链接，本地地址不具备公开网络可达性。

## 烧脑模式

打开 `/traffic/puzzle.html`，或点击顶部「烧脑」。三张固定空间规划题为 5×5 / 6×6 / 8×8，分别有 3 / 4 / 6 组住宅和站点，均可直接选关。最终图已升级为「配额困局」：每线必须分别占11/11/11/10/10/11格（含两端），B/E线路必须经过同字母◇站。旧最终图可通过长蛇填空的问题已通过独立配额约束消除。

没有时间限制：连接所有同字母端点、线路不交叉不共格、覆盖全部格子，三项全部成立才通关。全部接通但未覆盖全图时，会自动标橙剩余格。点击发车验收可检查布局，未通过不清空、不扣机会；通过后播放车辆送达动画。

支持拖动、逐格点击、键盘方向键与空格、回退、撤销、清除单线和清空重画。当前图布局自动保存，切换玩法或刷新可恢复；切换题目会重新开始该题。成绩与竞速分开存储，按最少修订次数记录；模拟5秒广告提供一条参考路线，领取后标记辅助通关。

```sh
node traffic/puzzle.test.mjs
node --check traffic/puzzle.mjs
```

验证所有参考解、反向画线、断路、跳格、交叉、回退和已连通但漏覆盖的拒绝逻辑。尚未以真人样本验证难度、留存或通关率。

最终题可用 `python3 traffic/verify-puzzle.py` 独立穷举验证：307条符合单线约束的候选路线，经14083个搜索节点找到且仅找到一个全局解。唯一解不等于已验证的真人难度；不承诺特定5%通关率。旧最终题记录不参与新版成绩，新版首次加载会重新开始最终图。

## 分批开城（重玩体验原型）

入口 `/traffic/city.html`，导航中为「开城」。每局三批，依次激活2/4/6组住宅与站点。只要求所有当前线路接通且满足预算，不需要覆盖全图，不计时。

- 下一批端点以虚线提前展示；道路占用未来地址时给出预警。
- 每批通车播放车辆送达、提示+40户并任选一个真实工具：立交（允许一个共用格）、隧道（直线跨过一格）、道路包（预算+6）。
- 通车旧线锁定；每批一次免费改线。未通车路线可反复修改、撤销、清除，道路与在用工具可回收。
- 选错后可以免费回退上一批一次，模拟5秒广告再提供一次额外回退（标辅助）；提前关闭不发奖励。免费重开同一城市不限次数。
- 结束记录城市编号、道路用量、回退次数及辅助标记。当前布局自动保存，刷新可续玩。
- 城市由两张已验证底图的旋转、镜像和入住顺序组合，编号确定同题；不是无限独立生成的题库。当前无真人留存或重开率结论。

测试：`node traffic/city.test.mjs`。覆盖100个城市编号×三批的可行解、锁定与免费改线、回退快照、额外广告回退限制、立交和隧道实际效果、资源回收、未来住宅冲突诊断。

## 下班弹射（手感原型）

入口 `/traffic/flick.html`。五辆小车，四个不限颜色的车位，最多五次弹射；当前同时停好四辆才算通关。拖住任意车向后拉、松手发射，可借墙反弹、推动其他车；一发多停有连击反馈。轻点或取消不扣次数，车辆运动中不能再次发射。已入位的车辆仍可被撞出。

无倒计时、广告或养成。可以免费重试同一开局，或换一个微调小车起始位置的开局；地图障碍和车位位置暂时固定。按 `1–5` 选车，方向键瞄准/调整力度，空格发射，Esc取消拖拽。帮助弹窗和切后台暂停物理推进。音效默认关闭，可主动开启。

物理采用120Hz固定步长、圆形碰撞近似、摩擦与反弹；车位中心29单位内且速度低于95时自动停入，非精确车辆物理。浏览器仅保存最佳入位数、单发连停和通关次数。检验：`node traffic/flick.test.mjs`，覆盖冲量、射击限制、停车/撞出、连击、胜负、确定性回放、29种开局稳定性，以及首局四发真实通关方案。好玩程度与重玩意愿尚需真人验证。

### 弹射第二版

新增三个可直接切换的停车场：经典图、弹簧图、连停图。弹簧图的青色圆桩会加力反弹，每车每次出手最多一次，速度封顶950。连停图调整车位和车辆位置，已验证首发 `(car 0, vx 20, vy -495)` 可真实碰撞双停。

一发新停稳至少两辆可额外获得一发，每局一次；发射前已停好的车重新入位不计新连停，离位后未停稳也不发奖励。三星条件为通关时剩余至少两发或打出双停，剩一发二星，其他通关一星；三张图的最佳星级保存本机。通关可直接去下一张图。自动测试包含三图真实通关、双停发奖、反复入位防重复奖励、弹簧触发上限和运动收敛。物理与反馈仍待真人手感校准。

### 再挤一个（squeeze.html）
个人摇杆闯关：控制橙色「我」，挤过人群到达车厢绿色区域并站稳。地铁/公交各三站，后续增加人群。碰撞推挤消耗体力，松手恢复；每站三次「借过一下」推开周围乘客。虚拟摇杆或方向键/WASD 移动，空格借过。无倒计时、付费或真实广告。使用自行实现的简化圆形人群碰撞，无第三方游戏代码或素材。
验证：`node traffic/squeeze.test.mjs`，覆盖输入有效性、体力恢复、技能次数、终点判定，以及两种车厢首站实际移动通关。

### 深圳挤地铁更新
- 岗厦北、车公庙、后海三个可直选的独立场景，客流与拥挤程度为游戏设定，不代表真实运营路线或客流。
- 主动下车人流、重量不同的背包客、惯性与身体倾斜；体力耗尽踉跄恢复，不直接判负；目标区域连续站稳 1.5 秒通关。
- 机制参考：Crowd Simulator（https://store.steampowered.com/app/1141650/）与 jiditie（https://github.com/ns2250225/jiditie ，查阅提交 b446f05）。后者未发现明确许可证，本项目未导入其源码或资源，沿用自己的 Canvas 实现。
- 站名核对：深圳市交通运输局 https://jtys.sz.gov.cn/zwgk/ggqsydw/dt/index.html 。本原型与深圳地铁无隶属关系。
- 尚未实现完整 3D 布娃娃、全线战役、随机客流事件和成就系统。

### 极限泊车（parking.html）
停车分类现在包含弹射与驾驶两种模式。驾驶版为独立原创 Canvas 原型，无新增依赖：倒车入库、侧方停车、柱旁泊车三关。左手方向盘/方向键转向，右手前进与倒车，松开踏板刹停；车身完全入位、朝向误差低于约 5°、停稳 1 秒通关。擦碰不终止练习，支持回退上一段换向操作。当前为低速运动学模型，无真实广告、联网排行或驾驶教学认证。

验证：`node traffic/parking.test.mjs` 与 `node traffic/navigation.test.mjs`。
