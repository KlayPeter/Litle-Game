# 末日卡牌堆 · 余烬

一个可以直接在浏览器里玩的单机卡牌生存游戏：10 天、一座营地、3 个电台零件，撑到救援。

> 这是 Web 游戏原型，不是微信小游戏代码；但玩法、数值、UI 都按“以后能缩到小游戏”的方向做。

![游戏预览](preview.png)

## 直接玩

双击 `index.html`，用 Chrome / Edge 打开即可。无需安装、无需构建、无需服务器。

如果想在线玩：在 GitHub 仓库 **Settings → Pages** 里把 Source 设为 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存后访问 GitHub Pages 地址即可。

手机测试（可选）：

```bash
python -m http.server 8000
```

手机访问电脑局域网 IP 的 8000 端口。

## 玩法

- **目标**：撑到第 10 天，集齐 3 个电台零件，建电台，呼叫救援。
- **每天 3 行动点**：打牌、探索各消耗 1 点；结束白天进入夜晚。
- **打牌**：点手牌 → 点营地空位。卡牌有资源费用。
- **合成**：点两张营地牌，例如木墙+木墙=庇护所、木墙+哨塔=堡垒、幸存者+猎弓=猎人、农场+集水器=温室。
- **相邻加成**：篝火挨着厨师、农场挨着集水器、哨塔挨着木墙、工作台挨着工程师等。
- **夜晚**：营地生产 → 所有人吃饭 → 怪物袭击。防御不够就要牺牲一张营地牌；没牌就死人。
- **探索**：每天一次，去超市/五金店/医院/加油站/避难所/废弃电台。电台零件只在废弃电台。
- **救援**：3 个零件 + 电台卡，撑到第 10 天 = 好结局；否则是“活下来但没等到救援”。
- **空投补给**：每局一次，模拟广告，食物 +2、木头 +2、金属 +1。

## 内容量

- 19 张卡牌：幸存者、拾荒者、工程师、医生、猎人、厨师、守卫、篝火、木墙、哨塔、庇护所、农场、集水器、工作台、猎弓、陷阱、电台、堡垒、温室。
- 6 个探索地点、5 个随机事件、3 种结局。
- 4 个合成配方、7 组相邻加成。
- 一局约 8-15 分钟。

## 已知限制

- 没有微信登录、真实广告、云存档、排行榜。
- 数值只做了第一轮平衡，极端打法可能过难/过易。
- 手机小屏需要滚动；桌面/平板体验最好。
- 没有多周目/解锁；目前一局 10 天。
