# 上班下班 · 七点，海边见

三个同事约好周五下班去海边聚餐。帮助阿停停车、小路疏通晚高峰、小深挤上深圳地铁，把三种玩法串成一个下班故事。

1. **阿停 · 下班接单**：三单一轮，弹射停车后选择收下保底或继续冲高分；另有经典弹射和精准泊车。
2. **小路 · 路线挑战**：竞速模式与不限时解谜模式。
3. **小深 · 挤地铁深圳版**：移动、扒拉、上车和通勤战役。

## 本地运行

在项目根目录运行 `python3 -m http.server 8765`，打开 http://127.0.0.1:8765/ 即进入统一故事大厅。所有玩法都能返回大厅，自由选择，不强制解锁。

挤地铁源码与构建说明见 [来源记录](traffic/jiditie-source/UPSTREAM.md)，其余玩法说明见 [traffic/README.md](traffic/README.md)。本地存档不会上传，广告仅模拟。

旧卡牌项目保留在 `legacy-cards.html`，不列入三款游戏入口，说明见 [旧项目文档](LEGACY-CARDS.md)。
