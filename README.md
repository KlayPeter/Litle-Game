# 末日卡牌堆 · 余烬 2.0

一个可以直接在浏览器里玩的单机卡牌生存游戏：15 天、一座营地、3 个电台零件，撑到救援。

> 这是 Web 游戏原型，不是微信小游戏代码；但玩法、数值、UI 都按“以后能缩到小游戏”的方向做。

![游戏预览](preview.png)

## 直接玩

双击 `index.html`，用 Chrome / Edge 打开即可。无需安装、无需构建、无需服务器。

如果想在线玩：在 GitHub 仓库 **Settings → Pages** 里把 Source 设为 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存后访问 GitHub Pages 地址即可。

手机测试（可选）：

```bash
python -m http.server 8000
```

手机访问电脑局域网 IP 的 8000 端口。

## 2.0 新增了什么

- **15 天**长局，分 3 幕；第 15 天判定救援。
- **4 行动点/天**，能做的事情更多。
- **卡牌升级**：木墙/哨塔/庇护所/农场/集水器/篝火/工作台都能升 Lv.2-3，属性随等级提升。
- **工坊制造**：花资源直接造牌，不用等抽牌。
- **营地行动**：加固防线、热汤、治疗、研究、空投补给。
- **探索队伍**：派 1-2 名幸存者出门，选地点，带回资源/卡牌；外出的人当晚不防守，也可能受伤。
- **士气**：低士气会降低生产，归零会崩盘；热汤、事件、天气都会影响。
- **天气/柴火**：晴、寒潮、暴雪、浓雾、回暖；每晚烧柴，柴不够会冻伤。
- **受伤**：幸存者受伤后 1-2 天不能工作/探索；药品可以治疗。
- **更长的合成链**：7 个合成配方，例如木墙+陷阱=尖刺墙、庇护所+农场=家园、哨塔+陷阱=瞭望塔。
- **破防选择**：夜袭防御不够时，可以牺牲一张牌，或者让一个人受伤。

## 玩法

- **目标**：撑到第 15 天，集齐 3 个电台零件，建电台，呼叫救援。
- **每天 4 行动点**：打牌、探索、工坊制造、营地行动都要花 AP。
- **打牌**：点手牌 → 点营地空位。卡牌有资源费用。
- **升级**：点营地牌 → 详情里点“升级”。升级需要资源 + 研究点。
- **合成**：点两张营地牌，例如木墙+木墙=庇护所、木墙+陷阱=尖刺墙。
- **相邻加成**：篝火挨着厨师、农场挨着集水器、哨塔挨着木墙、工作台挨着工程师等。
- **夜晚**：烧柴 → 营地生产 → 所有人吃饭 → 怪物袭击。防御不够就要牺牲牌或让人受伤。
- **探索**：每天一次，派 1-2 人；电台零件只在废弃电台。
- **救援**：3 个零件 + 电台卡，撑到第 15 天 = 好结局；否则是“活下来但没等到救援”。

## 操作

- 点手牌选中；点营地空位打出。
- 点营地牌查看详情；再点另一张尝试合成；详情里可升级。
- `探索`：选人 → 选地点。
- `工坊`：花 1 AP + 资源制造卡牌。
- `行动`：加固/热汤/治疗/研究/空投。
- `结束白天`：进入夜晚。
- 右上角可以开关声音、重看教程。
- 每局一次“空投补给”（模拟广告）：食物 +2、木头 +2、金属 +1。

## 内容量

- **22 张卡**：7 类幸存者 + 15 类建筑/道具/合成物。
- **7 个合成配方**、**7 组相邻加成**、**6 个探索地点**、**6 个随机事件**。
- 3 种结局；一局约 15-25 分钟。

## 已知限制

- 这是 Web 原型，没有微信登录、真实广告、云存档、排行榜。
- 数值只做了第一轮平衡，极端打法可能过难/过易。
- 手机小屏需要滚动；桌面/平板体验最好。
- 没有多周目/解锁；目前一局 15 天。
